# Source Code Directory

## Structure

```
src/
├── core/           # Core game engine
├── towers/         # Tower classes and logic
├── enemies/        # Enemy classes and AI
├── ui/             # User interface components
├── utils/          # Utility functions
├── maps/           # Game maps and levels
└── index.js        # Main entry point
```

## Modules

- **core/** - Game loop, physics, collision detection
- **towers/** - Tower definitions, upgrade system
- **enemies/** - Enemy types, pathfinding, spawning
- **ui/** - HUD, menus, controls, overlays
- **utils/** - Helpers, math, constants
- **maps/** - Level definitions, terrain data

See issues for implementation tasks.
